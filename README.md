# Bank Management System 🏦

A multi-tier Windows Forms desktop application built in C# for managing bank accounts, clients, employees, and secure transactions.

## 🚀 Key Features
- **Client & Employee Management:** Add, update, search, and track profiles.
- **Account Operations:** Open new bank accounts, issue/renew visas, and manage cheque books.
- **Transactions:** Seamlessly handle deposits, withdrawals, and account-to-account transfers.
- **Role-Based Security:** Secure user login system with granular permission settings and audit logs.
- **Structured Multi-Tier Architecture:** Clean separation between UI, Business Logic, and Data Access layers.

## 🛠️ Architecture & Tech Stack
- **Language:** C#
- **Framework:** .NET Framework / Windows Forms (WinForms)
- **Architecture:** 3-Tier Architecture
  - **Presentation Layer:** WinForms UI & Custom User Controls
  - **Business Logic Layer (`Bank_Business`):** Core business rules and object models
  - **Data Access Layer (`BankDataAccess`):** Database interaction and queries
